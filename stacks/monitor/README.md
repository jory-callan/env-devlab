# Observability Stack — Quick Deployment Guide

## Overview

VictoriaLogs + Fluent Bit + Grafana (VFG) is a complete log collection,
storage and visualization stack.

### Architecture

```
+--------------+     +--------------+     +--------------+     +--------------+
| Applications | --> |  Fluent Bit  | --> | VictoriaLogs | --> |   Grafana    |
|              |     |              |     |              |     |              |
| - Nginx      |     | - collect    |     | - store      |     | - visualize  |
| - Java apps  |     | - parse      |     | - fast query |     | - alerting   |
| - others     |     | - filter     |     | - compress   |     | - dashboards |
+--------------+     +--------------+     +--------------+     +--------------+
```

All components join the external `net-shared` bridge network, so they
resolve each other by service name (`victorialogs`, `fluentbit`, `grafana`).

## Prerequisites

- Linux (CentOS 7+ / Ubuntu 18+ or newer)
- Docker 20.0+ with the Compose v2 plugin (`docker compose`)
- At least 2 GB RAM and 10 GB disk space
- The shared network: `bash ../../create-network.sh`

## Quick deployment

```bash
# 1. Set permissions (creates directories and fixes ownership)
sudo bash tools/setup-permissions.sh

# 2. Start all services
bash tools/start-all.sh

# 3. Verify the deployment
curl http://localhost:9428/health
curl http://localhost:3000/api/health
curl http://localhost:2020/
```

## Default credentials

Grafana: see `GF_SECURITY_ADMIN_USER` / `GF_SECURITY_ADMIN_PASSWORD`
in `.env` (default `admin` / `admin123`).

## Adding log sources

1. Copy the matching template from `fluentbit/conf/`
   (`nginx-logs-template.conf`, `java-logs-template.conf`, or
   `custom-logs.conf`).
2. Add the `[INPUT]`/`[FILTER]` blocks to `fluentbit/conf/fluent-bit.conf`
   or include the file with `@INCLUDE your-logs.conf`.
3. Restart Fluent Bit: `cd fluentbit && docker compose restart`

## Grafana configuration

### Data source

The data source provisioning file is generated by
`grafana/tools/generate-datasource.sh` (run automatically by
`tools/start-grafana.sh`):

- Type: `loki` (VictoriaLogs is LogQL-compatible) and `prometheus`
  (LogSQL endpoint)
- URL: `http://victorialogs:9428` (service name on net-shared)

### Basic query syntax

```bash
# All logs
{service="nginx"}

# Error logs
{service="nginx"} |= "ERROR"

# Java application logs
{service="java-app"} |= "Exception"

# Time range query
{service="nginx"} | time("5m")
```

## Troubleshooting

### Common issues

1. **Port conflict**
   ```bash
   netstat -tlnp | grep :9428
   # Adjust the port mapping in the component docker-compose.yaml
   ```

2. **Permission issues**
   ```bash
   sudo bash tools/setup-permissions.sh
   ```

3. **Disk space**
   ```bash
   df -h .
   # Clean up logs or add disk space
   ```

4. **Out of memory**
   ```bash
   free -h
   # Adjust the memory settings in the component docker-compose.yaml
   ```

### Log debugging

```bash
# Inspect the Fluent Bit configuration
docker exec fluentbit cat /fluent-bit/etc/fluent-bit.conf

# Test the VictoriaLogs connection
curl -X POST "http://localhost:9428/insert/jsonline" \
  -H "Content-Type: application/json" \
  -d '{"timestamp":"2024-01-01T00:00:00Z","message":"test log","level":"info"}'

# Query the test log
curl "http://localhost:9428/select/logsql/query" -d 'query=message:test'
```

### Network diagnostics

```bash
# Check the Docker network
docker network ls
docker network inspect net-shared

# Test container-to-container connectivity
docker exec fluentbit ping victorialogs
docker exec grafana ping victorialogs
```

## Production notes

### Security

- Change the default Grafana password in `.env`
- Configure HTTPS access
- Restrict network access
- Update image versions regularly

### Performance

- Tune VictoriaLogs memory settings based on log volume
- Configure Fluent Bit buffer sizes
- Set log rotation and retention policies
- Monitor system resource usage

### High availability

- Run VictoriaLogs in cluster mode
- Set up Grafana HA
- Configure load balancing
- Implement a backup strategy
